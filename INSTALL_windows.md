# Environment Verification on Windows 11 (Docker Desktop + WSL2)

This document records the environment verification of the PERIOD toolchain performed by
Wang Ziqi (1240007116) on a Windows host, on 2026-11-08. It follows the upstream
Docker-based workflow referenced in [INSTALL.md](INSTALL.md) and documents the deviations
required for a Windows machine.

## Host environment

| Item | Value |
| --- | --- |
| Host OS | Windows 11 Pro |
| WSL | WSL2, installed via `wsl --install --no-distribution` |
| Container runtime | Docker Desktop (per-user install, WSL2 backend) |
| Image | `wcventure/period:stable`, retagged locally as `period:latest` |

## Container launch

The container was started in privileged mode, which PERIOD requires for its
SCHED_DEADLINE-based periodic scheduling, with a host directory mounted for results:

```powershell
docker run --privileged -it -v D:\cs340\results:/results period:latest
```

The verified runtime configuration (`docker inspect serene_austin`; container name was
auto-generated by Docker):

| Property | Value |
| --- | --- |
| Privileged | `true` |
| Working directory | `/workdir/PERIOD` |
| Mounts | `D:\cs340\results` -> `/results` |
| Entry command | `/bin/bash` |

All experiment logs and bug reports are written to the mounted `/results` directory so
they persist after the container exits.

## Deviations from the upstream setup

| Item | Original setting | Setting used | Reason |
| --- | --- | --- | --- |
| Host OS | Ubuntu 18.04+ (native Linux) | Windows 11 Pro | Available machine runs Windows; Docker provides the required Linux environment |
| Docker installation | `apt install docker.io` | Docker Desktop, per-user, WSL2 backend | Windows host |
| Image reference | `wcventure/period:stable` | same image, local tag `period:latest` | Convenience only; image content unchanged |
| Docker proxy | not required upstream | Docker Desktop proxy configured manually | Docker does not use the Windows system proxy by default; without it, image pulls time out |
